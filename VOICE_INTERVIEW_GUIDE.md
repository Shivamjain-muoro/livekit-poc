## 🛠️ Setup Instructions

### **1. Install Voice Dependencies**
```powershell
# Run the comprehensive setup
python setup_voice_system.py
```

This will install:
- `pyttsx3` - Text-to-Speech
- `SpeechRecognition` - Speech-to-Text
- `aiohttp` - Async HTTP client
- `google-generativeai` - Gemini LLM

### **2. Configure Environment**
Update your `.env` file:
```bash
# Google Gemini (Required for intelligent evaluation)
GOOGLE_API_KEY=your_google_api_key_here

# LiveKit (Required for video/audio)
LIVEKIT_API_KEY=your_livekit_api_key
LIVEKIT_API_SECRET=your_livekit_secret
LIVEKIT_URL=wss://your-livekit-url

# Backend
BACKEND_URL=http://localhost:8003
```

### **3. Start the System**
```powershell
# Start the voice-enabled backend
python realtime_voice_backend.py
```

Backend will start on: `http://localhost:8003`

## 🔧 Troubleshooting

### **Common Issues & Solutions**

| Issue | Solution |
|-------|----------|
| No microphone detected | Grant browser microphone permissions |
| TTS not working | Install: `pip install pyttsx3` |
| STT errors | Install: `pip install SpeechRecognition` |
| Gemini evaluation fails | Set `GOOGLE_API_KEY` in .env |
| LiveKit connection issues | Check LiveKit credentials |
| Backend not responding | Restart: `python realtime_voice_backend.py` |
